# Chrono Planner

Chrono Planner 是 Chrono Desk 的獨立排程模組。它使用原生 JavaScript，不載入外部 CDN，資料保存在目前瀏覽器的本機儲存空間。

## 開啟

在此資料夾執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。GitHub Pages 可直接從本資料夾的 `index.html` 開啟。因為採用 JavaScript 模組，請透過 HTTP 伺服器開啟，不要直接用 `file://`。

## 已實作

- 週／日行事曆、快速新增、拖曳排入、可調整時長的快速排程建議；另有獨立的月曆頁面檢視匯入行程。
- 計畫與實際分開記錄、活動分類與狀態標籤分層、跨午夜統計切分。
- 重複行程（每日／每週／每月），可編輯單次、這次及之後或整個系列。
- 重疊提醒後仍可保存；不自動搬動固定行程。
- 本機自動保存、復原、JSON 匯入／匯出、ICS 匯入／匯出、CSV 匯出；匯入行程會標記匯入時間並顯示於「匯入日曆」。
- 分類計畫／實際比較、每週回顧、知識主題卡、行動裝置單日版面。

## 目前範圍

- 重複行程目前預先建立未來 365 天的活動；編輯系列會套用到選定範圍內已建立的活動。
- ICS 匯入支援常見的單次日期時間活動；時區、全天與外部重複規則尚未完整支援。匯出會將目前已建立的活動逐筆輸出。
- 資料僅存於目前瀏覽器，不提供帳號或雲端同步。匯入前會顯示行程預覽與重複處理方式。

## 測試

在此資料夾執行 `npm test`。核心排程、日期切分、重複行程與分析公式使用 Node 內建測試框架。
