# 健康時間公式知識庫

初步整理運動時間、睡眠與休息時間的公式和研究來源，做為後續知識主題的可擴充起點。此專案是獨立離線網頁，不會改動 Chrono Planner 排程主畫面。

## 開啟

下載整個 repository，保留 `index.html`、`data/`、`src/` 的相對位置，再以瀏覽器開啟 `index.html`。不需安裝套件或啟動伺服器；外部來源只在使用者點擊文獻連結時開啟。

## 功能

- 50 項運動公式與 56 項睡眠／休息公式，可依分類搜尋。
- 公式卡顯示方法、證據標籤與相關來源。
- 成人有氧週量與單晚睡眠日誌試算器，含輸入錯誤檢查。
- 運動原則 15 條、睡眠／休息原則 15 條、注意事項 30 條。
- 新增個人知識條目，存在瀏覽器本機；可匯出／匯入 JSON 備份。
- 不使用外部套件、雲端 API 或帳號；不讀取或上傳個人規劃資料。

## 擴充方式

基礎公式資料位於 `data/health-data.js`；互動、計算、搜尋和 JSON 匯入／匯出位於 `src/app.js`；版面位於 `index.html`。後續新增主題可沿用資料欄位：

`id, domain, name, equation, method, evidence, category, sourceUrls`

新增公式時應附適用範圍、計算方法、限制和來源；如屬程式自訂估算，證據標籤須明確標示。

```json
{
  "schemaVersion": 1,
  "kind": "health-time-kb-custom-items",
  "exportedAt": "2026-10-16T00:00:00.000Z",
  "items": [
    {
      "id": "custom-example-1",
      "domain": "exercise",
      "name": "範例指標",
      "equation": "完成分鐘 ÷ 目標分鐘 × 100%",
      "method": "用於自我追蹤；不是診斷門檻。",
      "evidence": "程式自訂",
      "category": "目標進度",
      "sourceUrls": []
    }
  ]
}
```

## 證據標籤和限制

- **指南／標準**：出自正式指南或標準化測量方法。
- **研究指標**：研究中使用或檢驗過；不等於因果證據或個人診斷。
- **程式自訂**：供排程和自我觀察的計算方式，無通用醫療門檻。
- **待查證**：內容尚未完成文獻核對。

本頁不是醫療工具。睡眠缺口屬規劃估算；RPE、MET、最大心率和負荷比會受測量方法限制。睡眠資料不能用來診斷失眠。成人活動建議不應直接套用所有年齡或健康狀況。

## 文獻

文獻連結和條目位於知識庫「文獻來源」頁。來源優先採 WHO、共識聲明、PubMed/PMC 和同行評審系統性回顧；每個指標的適用限制另見卡片說明。
